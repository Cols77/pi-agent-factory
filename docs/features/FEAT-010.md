# FEAT-010 — COHERENCE-CONSOLE

Status: declared feature dossier (Inc-9 health-resolution, decision-level register).

This feature registers **COHERENCE-CONSOLE** in the Coherence / pi-agent-factory feature set. It covers the shared browser dashboard (health + dossier + teach) and the common projections used by Pi and Hermes surfaces.


## Design boundary

The console renders canonical Coherence projections and never becomes an authority of its
own. It distinguishes the canonical Coherence Run from operational Kanban state:

- Run assurance status: contract, GatePlan, evidence, traceability, human decisions, and
  final pass/conditional/blocked status.
- Operational stage status: Kanban card, assignee, attempt, heartbeat, handoff, and worker
  lifecycle.

The console exposes the immutable execution-contract hash, expected workflow-specific gate
floor, additional-gate proposals, onboarding/change-control decisions, evidence, and the
required tracer-bullet explanation. Behavior-changing work also exposes the course delta,
before/after evidence, and the human teaching/acknowledgement interaction.

Pi, Hermes desktop, and the Hermes dashboard are renderers over the same backend state and
event stream. Editing an operational card cannot change the Coherence contract.
